# Tracking Website

This project is a tracking website that allows users to input tracking information and view the status of their shipments. It is designed to be user-friendly and provides real-time updates on tracking data.

## Project Structure

```
tracking-website
├── html_files
│   └── index.html       # Main HTML document for the tracking website
├── css
│   └── styles.css       # Styles for the tracking website
├── js
│   └── scripts.js       # JavaScript code for handling user interactions and fetching data
└── README.md            # Documentation for the project
```

## Setup Instructions

1. Clone the repository to your local machine.
2. Open the `index.html` file in a web browser to view the tracking website.
3. Ensure that the `css/styles.css` and `js/scripts.js` files are linked correctly in the HTML document.

## Usage Guidelines

- Enter your tracking number in the input field provided on the webpage.
- Click the "Track" button to fetch the tracking information.
- The tracking status will be displayed dynamically on the page.
